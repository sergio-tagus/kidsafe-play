# SafeTube Kids — Brand

## Master
`logo-mark-source.png` (1024×1024) — the single source of truth. Regenerate every icon/splash from it with `python3 scripts/generate-icons.py`.

## Palette
| Role | Hex |
| --- | --- |
| Primary (coral) | `#FF6B9D` |
| Warning / accent yellow | `#FFD93D` |
| Fresh green | `#6BCB77` |
| Sky | `#4D96FF` |
| Cream background | `#FFF7ED` |
| Deep plum text | `#3C1E50` |

## Typography
- Display / headings: **Fredoka** (`@fontsource/fredoka`)
- Body: **Nunito** (`@fontsource/nunito`)

## Do / don't
- Do keep 10 % safe area around the mark.
- Do use the cream background `#FFF7ED` behind the mark on iOS (no transparency).
- Don't recolor the mane or the horn.
- Don't stretch the mark; regenerate at target size.
